Ce este acesta?

O interfață de test care rulează local în browser. Nu este Android, nu este ISO bootabil și nu schimbă sistemul Windows.

Pentru un VM Android x86 real este necesară o imagine de sistem Android compatibilă și un proces separat de personalizare AlbOS.
